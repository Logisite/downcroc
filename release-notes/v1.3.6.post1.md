# 1.3.6.post1

Extensions can now be installed as one file, like a small VSIX, instead of a
manifest that points at loose code somewhere on disk.

## What changed

Version 1.3.6 gave downcroc an extension host, capability grants, and the
`downcroc extension` command. It still expected you to place code on disk
yourself and write a manifest pointing at it. This release adds a packaged
artifact so someone can hand you one file to check and install.

Build an artifact from a directory containing `__main__.py` and
`downcroc-extension.toml`:

```sh
downcroc extension build ./my-extension --output reply-bot.pyz
```

The command prints the output path and its SHA-256. Install it with:

```sh
downcroc extension add reply-bot.pyz
```

The installer reads the manifest from the archive, copies the artifact under
your config directory, records the checksum, writes a derived manifest, and
reloads the host. The extension is installed but not enabled. Turn it on with
`downcroc extension enable <id>` after you decide what capabilities to grant.

## Verification

`downcroc extension verify <id>` recomputes the checksum and tells you whether
the installed artifact still matches. The host verifies the artifact again
before every launch and every one-shot test. A missing file or a changed file
stops the extension, logs `extension.artifact_invalid`, and runs no extension
code.

`extension list` and `extension show` now report the artifact path and whether
it was verified on the last check.

## What the checksum means

The checksum proves the file you installed is the same file you checked. It
does not prove the author is trustworthy. It does not sandbox the code. The
extension still runs as a child process with only the capabilities you granted,
and every capability call is still logged.

## Compatibility

Existing TOML manifest installs keep working. `downcroc extension add` accepts
both `.toml` and `.pyz`. Nothing about grants, events, or the JSON protocol
changed.

## Acceptance

Black-box tests build a small artifact, install it, run a one-shot test, then
corrupt the installed file and confirm that verification fails and no extension
code runs. The docs map, glossary, lock check, compileall, ruff, and format
checks all pass.
