# 1.3.4.post2

Adds `downcroc logs --chain`, a human-readable view that renders each log event
as a thin blue rounded box and joins them into one continuous chain.

## What changed

- `--chain` shows every event in its own blue card with level-coloured text and
  structured fields wrapped inside. Consecutive events are joined by a single
  centred `◆` bead, with no gap or stem line between them.
- The bead sits at the true midpoint of the boxes, computed from the rendered
  width, so the chain stays straight regardless of how long each event's text is.
- Long values wrap inside a card instead of being clipped. No log content is ever
  truncated in chain view.
- Works with `--follow` (each arriving event extends the chain), `--addresses`,
  and `--glyphs` (unicode by default, `ascii` falls back to `+`/`*`).
- `--json` is unchanged and takes precedence: it still emits raw one-line-per-event
  JSON, so machine consumers see no difference.

## What you should see

Run `downcroc logs --chain --limit 20` (or add `--follow` to watch live). Events
read top-to-bottom as a linked chain of blue cards. If you need the raw records,
`--json` behaves exactly as before.
