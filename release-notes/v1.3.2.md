# 1.3.2

`1.3.2` improves follow-up visibility, makes day-to-day CLI reading easier, fixes a few CLI and dispatch issues, and expands the bundled documentation. This release is additive and keeps JSON output stable (ISO timestamps).

## Follow-ups and batches

- **Follow-up outlook:** `downcroc followups due [--due today|7d|Nd|all]` shows a cross-batch view of follow-up work that needs attention, ordered by urgency with compact counts and due timing.
- **Batch thread view:** `downcroc batch thread <batch_id>` visualizes a batch and its follow-up conversation, including step state/timing, reply threads, and a per-recipient chain (`--recipient ADDRESS`) with the initial send, follow-up jobs, and inbound replies. Use `--all` to include every reply thread.
- **Parent batch summaries:** `downcroc batch list --parents [--sort recent|stale]` folds follow-up child batches into parent rows with declared steps, last follow-up, pending work, and last activity, so batches that need attention are easier to spot.
- Follow-up timing is surfaced consistently via `next_due_at` in outlook and thread views.

## CLI

- **Real sender on jobs:** `downcroc job show` and job listings display the real sending account/address for a job.
- **Mail reading:** `downcroc mail show` and `downcroc mail thread` render messages in a card-style view (headers, reply state, body, and attachments).
- **Relative times:** follow-up and activity times in the CLI display as relative durations (`s/m/h/d/mo`); machine-readable JSON continues to use ISO timestamps.
- **Docs list:** `downcroc docs --list` renders as a nested ANSI tree that mirrors the book hierarchy.
- **Docs browser:** lowered width thresholds so the docs browser layout works better on narrower terminals.

## API

- `GET /api/followups/outlook` returns the cross-batch follow-up outlook.
- `GET /api/batches/{id}/thread` returns the batch thread view (steps, threads, and optional per-recipient chain).
- Parent batch listing includes follow-up summaries.

## Fixes

- **Dispatch:** preserve the SMTP seat reason and rotate seats when idle, improving rotation behavior.

## Documentation

- Added Part II command docs for `followups due`, `batch thread`, and parent `batch list` flags (`--parents`, `--sort`).
- Expanded the bundled book with glossary and Part III reference material (pipeline, seats and threads, failures, states, safety, cookbook, troubleshooting, configuration), plus additional Part I/II pages and screen captures.
- Cleaned up the docs structure and aliases, removed superseded legacy pages, and improved docs tooling and checks.
- Rewrote the README for clarity and switched the architecture diagram to Mermaid.

## Tooling

- Added `scripts/bump_version.py` to bump the project version (via `uv`, `--frozen` by default) and scaffold `CHANGELOG.md`, release notes, and the book release-notes indexes.

## Upgrade notes

- No database migrations and no configuration changes are required for this release.
- Restart the daemon/service after upgrading to load the updated CLI and API behavior.
