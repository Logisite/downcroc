# 1.3.2

`1.3.2` adds follow-up visibility and improves CLI reading views.

## Follow-ups

- `downcroc followups due [--due today|7d|Nd|all]` shows a cross-batch follow-up outlook: which batches and steps are due now or coming up, with urgency ordering and compact counts.
- `downcroc batch thread <batch_id>` visualizes a batch and its follow-up conversation: step state/timing, reply threads, and a per-recipient chain (`--recipient`) with the initial send, follow-up jobs, and inbound replies rendered as message cards.
- `downcroc batch list --parents [--sort recent|stale]` folds follow-up child batches into parent rows with step, last follow-up, pending work, and last activity summaries.
- Follow-up timing now includes `next_due_at` in outlook and thread views.

## Mail and CLI

- `downcroc mail show` and `downcroc mail thread` render messages with a card-style view (headers, reply state, body, attachments).
- CLI follow-up and activity times display as relative `s/m/h/d/mo`; JSON output keeps ISO timestamps.
- `downcroc docs --list` renders as a nested ANSI tree matching the book hierarchy.

## API

- `GET /api/followups/outlook`
- `GET /api/batches/{id}/thread`
- Parent batch listing returns follow-up summaries.

## Docs

- Part II command docs added/updated for `followups due`, `batch thread`, and parent `batch list` flags.
