# 1.3.2.post8

Backfill now drains holes continuously instead of one page every five minutes.

## What changed

- A drain turn that fills holes keeps going without the five-minute cooldown. The
  cooldown applies only when a turn fills nothing, so recoverable holes are no longer
  limited to 46 per turn.
- The Sent-folder sweep is cached for the rest of the daemon run. The folder is scanned
  once, not again on every pass. A failed sweep still retries on a later pass.
- `backfill.imap_progress` reports sweep progress at each quarter mark, so a long scan
  no longer leaves the log blank.
- `backfill.account_started` now reports the holes still recorded for that account at the
  start of the turn, instead of the count from the beginning of the pass.
- Unlocking the vault still wakes backfill immediately, and `backfill.cooldown` and
  `backfill.resumed` explain each wait and early wake.

## What you should see

After upgrading and unlocking the vault, the first pass scans the Sent folder once with
progress lines, then fills the holes it can match in a few seconds. The log shows each
`backfill.resolved` as it is written. Holes that Gmail no longer has remain in the retry
schedule and are retried after the cooldown.
