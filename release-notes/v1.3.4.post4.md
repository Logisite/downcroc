# 1.3.4.post4

List commands now show the oldest entries first (newest at the bottom) by
default, with a `--newest-first` flag to invert the order.

## What changed

- `batch list`, `job list`, `failed list`, and `mail list` default to oldest
  first, so the newest entries appear at the bottom of the listing.
- Pass `--newest-first` on any of them to put the newest entries at the top.
- The order is applied in the query, before paging, so `--limit`/`--offset`
  still select the correct rows.

## What you should see

Run `downcroc batch list` and the most recent batch is the last row. Add
`--newest-first` and it is the first row. JSON output follows the same order.
