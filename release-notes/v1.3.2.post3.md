# 1.3.2.post3

A small, targeted release that makes the managed install survive a Python
interpreter upgrade, and turns a scary migration crash into a readable event.

## What you can do now

- **Your install self-heals after a Python minor-version upgrade.** The managed
  virtual environment's `python`, `python3` and `pythonX.Y` links are kept
  healthy, and the launcher's interpreter is verified.
- **`downcroc repair --json`** checks the managed install and fixes broken
  interpreter links. `downcroc doctor` now reports install health too.
- **`downcroc update` is self-healing.** It repairs the interpreter before and
  after installing a release, and falls back to uv's package installer when the
  venv has no pip module.
- **Migration failures are readable.** When the database is newer than the
  installed code, startup logs one structured `db.migrate_failed` event with
  the current revision, known revisions, and the next step, then exits with a
  short message. No more multi-page alembic tracebacks in `downcroc logs`.

## Upgrade notes

- No configuration or database changes are required.
- If your install already has broken links, run `downcroc repair` or just
  `downcroc update` — both repair them automatically.
- If your database was migrated by a newer release, install that release or
  newer. Downgrading downcroc below the database schema is refused with a
  clear message instead of a traceback.
