# 1.3.4.post1

Corrects the table rendering introduced in `1.3.4`. Boxed tables are once again
the default at every terminal width, wrapping long cell values onto extra lines
instead of switching to a stacked layout.

## What changed

- A table that cannot fit keeps its boxed grid and wraps cell content. It no
  longer switches to stacked fields on narrow terminals.
- `--stack` still switches to a stacked layout on demand; `--grid` forces the
  boxed grid and takes precedence over `--stack` or `cli.tables = false`.
- The documentation now describes this default accurately.

## What you should see

Run any listing as usual, even in a narrow window: tables stay boxed and long
values wrap. If you prefer stacked fields, pass `--stack` or set
`cli.tables = false`. No configuration change is required.
