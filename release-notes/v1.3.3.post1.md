# 1.3.3.post1

Release automation now publishes the repository release note as the GitHub release body.

## What changed

- The `release` workflow attaches `release-notes/<version>.md` as the GitHub release
  body instead of GitHub's auto-generated changelog, and titles the release
  `downcroc <version>`. When the repository has no note file for a tag, the release
  is still created, just without a custom body.

## What you should see

New tagged releases appear on GitHub with the same "What changed" and "What you
should see" text you read here, without a manual edit after the workflow runs.
