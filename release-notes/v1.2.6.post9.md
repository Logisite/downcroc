## IMAP watcher

- The IDLE heartbeat no longer calls `MailBox.noop()`, which does not exist in `imap-tools`. It sends `NOOP` through the underlying `imaplib` client instead.
- IDLE is now stopped idempotently. A failed heartbeat no longer sends `DONE` a second time, so the original error survives instead of being replaced by a `KeyError` that carries only an IMAP tag.
- Gmail and other IDLE servers no longer force the watcher to reconnect about every 60 seconds with `watcher.error` values such as `b'CKOD5'`.

## Version
