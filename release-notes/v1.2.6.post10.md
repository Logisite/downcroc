## Interactive CLI

- Command arguments no longer survive between invocations in the tree. Leaving a command with `b` and opening it again starts clean, so another field can be picked without pressing `x` first.
- Global flags still persist for the rest of the session. Only the command's own positionals and options reset.

## Dispatch

- When an account has due jobs but its daily allowance is spent, the dispatcher now logs `dispatch.allowance_spent` at warning level with the account, day, limit, and number of waiting jobs. It logs once per account per day and again after a cap increase is exhausted.

## Version

- `1.2.6.post10` is newer than `1.2.6.post9`, so `downcroc update` installs it.
