# 1.3.4.post3

Fixes the `--chain` log view introduced in `1.3.4.post2`: header text is
level-coloured again and the cards span the full terminal width.

## What changed

- The event header now uses the level's semantic colour (blue info, amber
  warning, red error) in bold instead of rendering as plain white/grey text.
- Chain cards no longer stop at 72 columns. They fill the available terminal
  width (with a small margin), so long lines wrap less and the view uses the
  whole screen.
- No log content is truncated; values longer than a card still wrap in full.

## What you should see

`downcroc logs --chain` now shows blue cards across the width of your terminal,
with coloured, bold event headers. Warning and error events stand out by colour.
`--json` remains unchanged.
