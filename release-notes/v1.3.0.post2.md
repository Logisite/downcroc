## Stats rebuild works on every mailbox

`1.3.0.post1` fixed how automatic sends are attributed, but the rebuild's
date-range helpers still expected the old job-row shape. That caused
`downcroc stats rebuild` and the post-prune rebuild to fail with:

```text
ValueError: too many values to unpack (expected 4, got 5)
```

This release updates the remaining readers to the same row shape.

**What you can do now:** run `downcroc stats rebuild` and get a normal result.
`downcroc mail prune --yes` no longer reports a server error after the mail has
already been removed.

## Automatic sending is still attributed correctly

The original fix is unchanged: sends from auto-routed jobs are counted against
the mailbox recorded in their send attempt, and jobs with no mailbox anywhere
are skipped instead of breaking the rebuild.

## Upgrade notes

- No database migration or configuration change is required.
- If you installed `1.3.0.post1`, upgrade to this release before running a
  rebuild.
