# 1.3.5

Collects the changes shipped since `1.3.4` across the post releases, plus a fix
for the interactive tree editor. Threads now render reliably, listings default
to oldest first, and the global flags work when you toggle them interactively.

## What changed

Since `1.3.4` the following shipped in point releases and is all included here:

- **Follow-up threading (`1.3.3.post2`).** Follow-ups now thread into the
  recipient's conversation regardless of transport. The daemon records the
  Message-ID actually delivered by Gmail, recovers it for older API sends, and
  builds `In-Reply-To`/`References` from that id. Old SMTP jobs were backfilled
  by the migration. Every decision is logged with the id used.

- **Table rendering (`1.3.4.post1`).** Boxed tables are the default again at
  every width and wrap long values instead of truncating them. `--stack` forces
  a stacked layout; `--grid` forces the boxed grid.

- **Chain log view (`1.3.4.post2`, `post3`).** `downcroc logs --chain` renders each
  event as a thin blue rounded box joined by a centred `◆` bead, with
  level-coloured headers and values that wrap without truncation. `--json` is
  unchanged.

- **List ordering (`1.3.4.post4`).** `batch list`, `job list`, `failed list`, and
  `mail list` default to oldest first (newest at the bottom). `--newest-first`
  inverts the order, applied in the query before paging.

This release adds:

- **Interactive tree editor.** The `--addresses`, `--stack`, and `--grid` flags
  can now be toggled with `space` in the option editor and are forwarded to the
  command when you press `r`. Previously they could not be toggled and never
  reached the command. A leftover default that forced `--addresses` on was
  removed.
- **Docs.** The input guide now recommends letting downcroc auto-generate keys
  rather than hand-writing them; only supply a key when you need a stable
  identifier or a step key.

## What you should see

Run downcroc as before. In the interactive tree, open a command's option editor
with `o`, toggle `--addresses`/`--stack`/`--grid` with `space`, and press `r` to
run; the generated command now includes the flags you selected. On the command
line, listings are oldest first unless you pass `--newest-first`. The update
check, follow-up validation, and table rendering from `1.3.4` continue to work.
No configuration change is required.
