# Preview and test

Before a message leaves your mailbox, you get a chance to see it. downcroc can
show you what it is about to send, check that a file makes sense, and let you
rehearse a submission without committing to it. Taking that moment is how you
turn "I think this is right" into "I have seen that this is right".

## Looking at the messages

**batch preview** takes the file you plan to send and shows you sample
messages as they will go out, with the details filled in. This is where you
read the subject, the greeting, and the body the way a recipient would, and
catch the small mistakes that only appear when real data meets real words.

Preview is especially valuable when a template and a spreadsheet work
together. A placeholder that looked fine on its own can produce an awkward
sentence once it is filled, and a preview is the cheapest place to notice.

## Checking and rehearsing

**batch validate** looks over a file and reports whether downcroc can read it
and what it found. It is the quick answer to "is this file shaped correctly?"
before you try to do anything with it.

When you submit, you can also choose a dry run. A dry run walks through the
submission without actually sending the mail, so you can confirm what would be
created. Together, validating, previewing, and rehearsing give you a path from
a draft file to a send you feel confident about.
