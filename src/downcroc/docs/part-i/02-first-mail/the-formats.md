# JSON or CSV

downcroc reads campaign files written as JSON, which is the format you have
seen in the last two pages: everything named, in one place, easy to read from
top to bottom. It can also read a CSV spreadsheet when you pair it with a
template that tells downcroc which column means what.

If your messages live in a spreadsheet, you do not have to rebuild them by
hand. This book keeps its focus on JSON because it shows every choice in the
open, and the details of sending from CSV live in Part II.
